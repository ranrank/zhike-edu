## 发现与调整

第一轮 8/9，偏好更新的断言误把新条目中“已放弃无人机森林巡检”这句历史说明判作旧偏好仍生效。
数据库实际已将旧条目失效。评分修正为按原条目 ID 核对生命周期；首次报告和 SSE 保留。

第二轮 8/9：更新本身正确，但只问当前方向时，回答仍附带已经放弃的旧方向。
在教务 AGENT_MAIN 提示词补充“只回答最新有效偏好，明确问历史时才说明历史”。
通过现有管理 API 更新当前知课教务人设，同时更新初始化文件和校验和；更新前提示词保存至
`resources/initializer/campus-assistant/.state/before-memory-current-direction.json`。
没有修改通用记忆抽取器、后台抽取阈值或数据库结构。

修改后新建账号完整重跑相同九题，最终 9/9；初始化数据完整性校验与两项既有 SSE 解析检查通过。

## 范围

这是本地虚构样例的功能验收，不代表任意问法下的长期记忆准确率。
本次未测试短期上下文压缩、容量淘汰或高并发，原有 28 题知识与资格评测也没有在本轮重新执行。
遗忘使记忆失效并停止后续注入，原始聊天与失效记录仍可审计，不等于物理擦除数据。
学生学籍与学分由业务库查询，长期偏好只为回答提供参考，不参与覆盖教务事实。
