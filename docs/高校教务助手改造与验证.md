# 高校教务助手改造与验证

更新：2026-10-19。

## 已落地

- 未新增 Maven / npm 依赖，沿用 AgentScope、Spring Boot、PostgreSQL、现有 RAG / pgvector / Elasticsearch、Redis 和 MCP。
- 前端品牌、输入提示和欢迎页示例改为知课教务；示例问题仅展示教务场景，旧问题记录保留。
- 新增六个 MCP 工具：学生画像、适用规则、选课资格、提交选课、请假申请、重修报名。
- 新增六张 campus_* 表，与商城表分离但复用现有业务数据源。启动只建表，演示数据显式初始化，不在重启时重置学生或申请。
- 资格判断先查画像，精确匹配专业、培养方案版本和有效期，再检查学籍、年级、已修学分、先修课、开放状态、名额及已报名状态；缺规则或规则冲突为 UNKNOWN。
- 选课 / 重修在事务内重新校验，使用学生与课程行锁、唯一约束保证幂等与名额正确性；请假同一申请标识幂等，成功为待审批。
- 写工具声明 readOnlyHint=false，沿用现有确认卡；不新增确认系统。
- 学籍与学分以业务数据库为准，意向方向等偏好沿用现有长期记忆；未新增记忆引擎。

## 知识库与切换

五篇虚构文档已实际上传并成功分块：CS-2022 / CS-2024 培养方案、选课重修规则、奖学金说明、请假流程。
两个版本的培养方案使用不同 Collection。课程资格由结构化规则精确匹配，当前没有额外实现向量级学生权限过滤器。
所有材料均标明是教学示例，不代表真实高校规则；写操作只作用于本地演示库，没有连接真实教务系统。

初始化器新增并激活知课教务人设，保留原有知识库、文档、对话、订单和其他业务记录。
切换前配置保存至 resources/initializer/campus-assistant/.state/before-campus.json；旧意图和技能停用，未删除。
Restore 可恢复切换前配置，前端品牌回退需单独恢复源码。

## 复现与使用

当前本地前端 http://127.0.0.1:5173/chat，后端 9090，MCP 9099。启动过程复用原有 DeepSeek / 百炼环境变量，未切换模型。

```powershell
# 本地配置与文档完整性校验
& resources/initializer/campus-assistant/run.ps1 -Action Validate
# 真实模型只读回归，不会提交选课或请假
node resources/regression/campus/verify.cjs
```

完整安装、回退及数据范围说明见 resources/initializer/campus-assistant/README.md。
